# Oven_Release

烤箱智能控制应用 | Smart Oven Control Application

## 语言支持 | Language Support

本应用支持中文和英文界面切换。

This application supports switching between Chinese and English interfaces.

### 切换到中文 | Switching to Chinese

应用内置语言切换功能。进入"设置 (Settings)"页面，选择语言时区设置 (Language & Time) 即可切换界面语言为中文。

The app has a built-in language switching feature. Go to the **Settings** page and select **Language & Time** to switch the interface language to Chinese.

- **菜谱 (Cookbook)**：包含开胃菜、早餐、主菜、甜点四大分类，共 28 道菜谱。
- **快速启动 (Quick Start)**：预设常用菜谱（鸡翅、鸡蛋松饼、煎蛋、热狗），可一键开始烹饪。
- **手动模式 (Manual)**：自定义温度与时间，灵活烹饪。

---

- **Cookbook**: Contains four categories — Appetisers (开胃菜), Breakfast (早餐), Entree (主菜), Desserts (甜点) — with 28 recipes total.
- **Quick Start**: Pre-set recipes (Chicken Wings, Egg Muffin, Fried Eggs, Hot Dog) for one-tap cooking.
- **Manual Mode**: Set custom temperature and time for flexible cooking.
